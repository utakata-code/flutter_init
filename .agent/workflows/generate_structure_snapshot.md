# プロジェクト構造スナップショットの生成

このワークフローは、現在の`lib/`構造をスナップショットとして `AI/specs/current_structure.md` に出力します。
AIエージェントが現在の実際の構造を把握するのに役立ちます。

## 手順

// turbo
1. 構造スナップショット生成
```bash
./AI/scripts/status/snapshot.sh
```

## 出力内容

- `lib/` 配下の全ディレクトリとファイルの構造
- 各フィーチャーの統計情報（層ごとのファイル数）
- 総ファイル数・ディレクトリ数
- 生成日時

## 使用タイミング

- AIエージェントとの会話開始前（現状把握のため）
- 大きな実装を完了した後
- プロジェクト構造の変更後
- ドキュメントを最新化したい時

## 出力先

`AI/specs/current_structure.md` (自動上書き)

## 関連コマンド

- `/status check` - 現在の状態をチェック
- `/status report` - チェック + 更新 + スナップショット
