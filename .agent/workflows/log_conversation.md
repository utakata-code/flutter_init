# 会話ログの記録

このワークフローは、AIエージェントとの会話内容を `AI/logs/conversation_log.md` に記録し、次回の会話でスムーズに引き継げるようにします。

## 使用タイミング

- 重要な実装や決定を行った後
- 会話セッションの終了時
- 問題解決や重大な変更を行った後
- Stage 完了時

## 手順

1. `AI/logs/conversation_log.md` を開く

2. 以下のテンプレートを「会話履歴」セクションの最上部に追加（最新が上）:

```markdown
---

## [YYYY-MM-DD HH:MM] 会話タイトル

**ステージ**: Stage X - ステップ名
**担当AIエージェント**: (エージェント名)
**会話ID**: (会話サマリーから取得)

### 🎯 目的・背景
（何を達成しようとしたか、なぜこの会話が必要だったか）

### 💬 会話の要点
- 主要な質問と回答
- 議論されたアプローチ

### ✅ 実施した作業
- 実際に行った変更
- 作成/修正したファイル

### 🔍 発見した問題
- エラーや警告
- 技術的な制約

### 💡 解決方法・決定事項
- 採用したアプローチとその理由

### 📊 影響範囲
- 変更したファイル一覧

### 📝 次回への引き継ぎ事項
- [ ] 未完了タスク

---
```

3. 各セクションを今回の会話内容で埋める

4. **次回への引き継ぎ事項**は特に詳しく記載する（次回の会話開始時に参照される）

## 注意事項

- **日時**: ローカル時間で記録（例: 2026-01-02 16:30）
- **会話ID**: Conversation History の ID を参照
- **最新が上**: 新しい会話は必ず既存のログより上に挿入
- **簡潔に**: 各セクションは要点のみ記載
