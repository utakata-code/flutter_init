### 2. 重要課題（必ず直すべき点）
```markdown
## ⚠️ 重要課題

### 課題1: Domain層での外部ライブラリ依存
**場所**: `task_entity.dart` 5行目
**問題**: `package:drift/drift.dart` をインポートしている
**理由**: Domain層は純粋なビジネスロジックのみを持つべきで、外部ライブラリに依存してはいけません
**修正案**:
```dart
// Before
import 'package:drift/drift.dart';

// After
// Domain層ではdriftを使用せず、純粋なFreezedクラスのみ定義
import 'package:freezed_annotation/freezed_annotation.dart';
```
```
