# レビューチェックリスト

## 1. アーキテクチャ準拠

### 層構造
- [ ] Domain層に外部ライブラリ依存がないか
- [ ] Infrastructure層がDomain層のインターフェースを正しく実装しているか
- [ ] Application層のProviderとNotifierの責務が分離されているか
- [ ] Presentation層にビジネスロジックが含まれていないか

### 依存の方向
- [ ] 上位層から下位層への一方向依存になっているか
- [ ] Domain層が他の層に依存していないか

## 2. コード品質

### 命名
- [ ] ファイル名が snake_case.dart になっているか
- [ ] クラス名が PascalCase になっているか
- [ ] 変数名が camelCase になっているか
- [ ] 意味のある名前が付けられているか

### 構造
- [ ] 1ファイル1クラスの原則に従っているか
- [ ] メソッドが長すぎないか（目安: 30行以内）
- [ ] ネストが深すぎないか（目安: 3レベル以内）

### コメント
- [ ] 日本語でコメントが記述されているか
- [ ] 複雑なロジックに説明があるか
- [ ] 公開APIにドキュメントコメントがあるか

## 3. 技術スタック準拠

### Riverpod
- [ ] @riverpod アノテーションが使用されているか
- [ ] ref.watch / ref.read が適切に使い分けられているか

### Freezed
- [ ] エンティティがイミュータブルか
- [ ] copyWith が適切に使用されているか

### Presentation
- [ ] HookWidget / HookConsumerWidget が使用されているか
- [ ] StatefulWidget が使用されていないか

## 4. パフォーマンス

- [ ] 不要な再ビルドを避けているか
- [ ] 重い処理が非同期で実行されているか
- [ ] リストが長い場合 ListView.builder が使用されているか

## 5. セキュリティ

- [ ] APIキーがハードコードされていないか
- [ ] ユーザー入力の検証が行われているか
- [ ] 機密情報がログ出力されていないか
