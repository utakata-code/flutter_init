# サンプル仕様書（参考例）

## メタ情報
- プロジェクト名: TaskManager App
- バージョン: v1.0
- 最終更新日: 2026-01-25
- 作成者: 泡沫Code

## 概要
- **コンセプト**: シンプルで直感的なタスク管理アプリ
- **目的**: 日々のタスクを効率的に管理し、生産性を向上させる
- **背景**: 既存のタスク管理アプリは機能が多すぎて使いにくい

## ターゲットユーザー・ペルソナ
- **主要ペルソナ**: 20-40代のビジネスパーソン
- **ユーザー課題**: タスクの優先順位付けが難しい
- **利用シナリオ**: 朝の通勤時に今日のタスクを確認

## ユースケース一覧
- UC-01: タスクを新規作成する
- UC-02: タスクの完了状態を切り替える
- UC-03: タスクを編集する
- UC-04: タスクを削除する
- UC-05: タスクをカテゴリ別に表示する

## スコープ定義
- **In-Scope**: タスクCRUD、カテゴリ管理、ローカル保存
- **Out-of-Scope**: クラウド同期、共有機能、リマインダー

## 機能要件

### F-01: タスク作成
- **説明**: 新しいタスクを作成できる
- **受け入れ基準**: 
  - タイトル必須
  - カテゴリ選択可能
  - 期限設定可能
- **依存関係**: なし

### F-02: タスク一覧表示
- **説明**: 登録済みタスクを一覧表示
- **受け入れ基準**:
  - 完了/未完了でフィルタ可能
  - カテゴリでフィルタ可能
  - 期限順でソート可能
- **依存関係**: F-01

## 画面設計
- **主要画面**: ホーム、タスク詳細、タスク作成、設定
- **画面遷移**: ホーム → タスク詳細 → 編集モード
- **ナビゲーション**: ボトムナビゲーション採用

## データ要件

### エンティティ: Task
| 属性 | 型 | 制約 |
|-----|------|------|
| id | String | 必須, UUID |
| title | String | 必須, 1-100文字 |
| description | String? | 任意, 最大500文字 |
| categoryId | String | 必須, FK |
| dueDate | DateTime? | 任意 |
| isCompleted | bool | 必須, デフォルトfalse |
| createdAt | DateTime | 必須 |
