# 推奨スタック: 選定理由とアーキテクチャ

このプロジェクトに必要に応じて導入する、実績のある定番推奨パッケージ群です。

## 通信: Dio
- REST API などとのインフラ層での通信が発生する場合、標準の実装の手間を省くため `dio` を使用します。Interceptors を用いた認証トークンの自動付与やエラーハンドリングが強力です。

## UI・画像: Cached Network Image / FontAwesome
- **font_awesome_flutter**: Flutter標準の Material Icons だけでなく、豊富なアイコンセットを扱う際に利用します。
- **cached_network_image**: リモート画像の表示において、キャッシュ機構による帯域節約やプレースホルダーの描画などの高い UX を提供します。

## ストレージ: SharedPreferences
- Drift（SQLite）を使うほどでもない、UIのテーマ情報などのごく簡単なキーバリューストア情報を端末に永続化する場合に選択します。

*※ その他、GPS や Firebase など特定のインフラに依存する機能が必要な場合は、適宜安定バージョンの追加をAIが判断して行なってください。*
