# 開発フロー

## 全体像

```
┌─────────────────────────────────────────────────────────┐
│                    開発フロー                           │
├─────────────────────────────────────────────────────────┤
│                                                         │
│  ┌──────────┐   ┌──────────┐   ┌──────────┐           │
│  │ Stage 1  │ → │ Stage 2  │ → │ Stage 3  │           │
│  │ 仕様策定 │   │ 構造計画 │   │   実装   │           │
│  └──────────┘   └──────────┘   └──────────┘           │
│       ↓              ↓              ↓                  │
│  仕様書作成    構造計画書作成   コード実装              │
│                                                         │
│            ↑ 仕様変更があれば前段階に戻る ↑            │
│                                                         │
└─────────────────────────────────────────────────────────┘
```

## Stage 1: 仕様策定

```
┌─────────────────────────────────────────┐
│ Step 1: ヒアリング                      │
│ - コンセプト、機能、ターゲット確認     │
├─────────────────────────────────────────┤
│ Step 2: 草案作成                        │
│ - 仕様書草案の作成・提示               │
├─────────────────────────────────────────┤
│ Step 3: 深掘り                          │
│ - 詳細仕様の確認・厳密化               │
├─────────────────────────────────────────┤
│ Step 4: 完成                            │
│ - 合意・仕様書確定                     │
└─────────────────────────────────────────┘
         ↓
   application_specification.md
```

## Stage 2: 構造計画

```
┌─────────────────────────────────────────┐
│ Step 1: ルール確認                      │
│ - アーキテクチャルール説明・合意       │
├─────────────────────────────────────────┤
│ Step 2: 草案作成                        │
│ - ファイル構成の計画・定義             │
├─────────────────────────────────────────┤
│ Step 3: レビュー                        │
│ - 網羅性・適切性の確認                 │
├─────────────────────────────────────────┤
│ Step 4: 完成                            │
│ - 合意・構造計画書確定                 │
└─────────────────────────────────────────┘
         ↓
   structure_plan.md
```

## Stage 3: 実装

```
┌─────────────────────────────────────────┐
│ Step 1: 開始                            │
│ - ルール再確認・状態確認               │
├─────────────────────────────────────────┤
│ Step 2: 計画                            │
│ - 実装順序の提示・合意                 │
├─────────────────────────────────────────┤
│ Step 3: レイヤー別実装                  │
│ ┌─────────────────────────────────────┐ │
│ │ 3-1: Domain層                       │ │
│ │ 3-2: Infrastructure層               │ │
│ │ 3-3: Application層                  │ │
│ │ 3-4: Presentation層                 │ │
│ └─────────────────────────────────────┘ │
├─────────────────────────────────────────┤
│ Step 4: レビュー                        │
│ - コードレビュー・修正                 │
├─────────────────────────────────────────┤
│ Step 5: 検証                            │
│ - 最終検証・ドキュメント確認           │
├─────────────────────────────────────────┤
│ Step 6: 完了                            │
│ - フェーズ完了報告                     │
├─────────────────────────────────────────┤
│ Step 7: 次へ                            │
│ - 次のフィーチャーへ（Step 1に戻る）   │
└─────────────────────────────────────────┘
         ↓
   動作するアプリケーション
```

## 各ステップで使用するコマンド

| ステップ | コマンド |
|---------|---------|
| 開始時 | `/status check` |
| 作業後 | `/status update` |
| 完了時 | `/status report`, `/detect_changes` |
| 検証時 | `/validate_structure`, `/flutter_analyze` |
