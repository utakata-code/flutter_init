# ステップ1: ヒアリング項目

## 必須ヒアリング項目

### 1. アプリのコンセプト
- **目的**: このアプリで何を実現したいですか？
- **解決したい課題**: どんな問題を解決しますか？
- **背景・文脈**: なぜこのアプリが必要ですか？

### 2. 主な機能
- **コア機能**: 必ず実装する機能は何ですか？
- **サブ機能**: あると便利な機能は何ですか？
- **優先順位**: 機能の優先度はどうですか？

### 3. ターゲットユーザー
- **主要ペルソナ**: どんな人が使いますか？
- **ユーザー課題**: ユーザーが抱える課題は？
- **利用シナリオ**: どんな状況で使いますか？

### 4. 参考アプリ
- **参考になるアプリ**: 似たようなアプリはありますか？
- **良い点**: そのアプリの良い点は？
- **改善したい点**: そのアプリで不満な点は？

## オプションヒアリング項目

### 5. 技術的要件
- **プラットフォーム**: iOS/Android/Web？
- **オフライン**: オフライン対応は必要？
- **認証**: ログイン機能は必要？

### 6. デザイン
- **テーマ**: 明るい/暗い/カスタム？
- **参考デザイン**: 参考にしたいUIは？
- **ブランドカラー**: 使用したい色は？
