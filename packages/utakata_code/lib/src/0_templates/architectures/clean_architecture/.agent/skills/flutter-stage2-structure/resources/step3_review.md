# ステップ3: レビュー観点

## レビューチェックリスト

### 1. 網羅性
- [ ] 仕様書のすべての機能がカバーされているか？
- [ ] 必要なエンティティがすべて定義されているか？
- [ ] すべてのユースケースに対応するファイルがあるか？

### 2. ファイル分割の適切性
- [ ] 1ファイルの責務が単一か？
- [ ] ファイルが大きくなりすぎていないか？
- [ ] 関連するファイルが適切なディレクトリにあるか？

### 3. 役割分担の過不足
- [ ] Domain層に実装詳細が含まれていないか？
- [ ] Infrastructure層がDomain層に正しく依存しているか？
- [ ] Presentation層がビジネスロジックを持っていないか？

### 4. 計画解像度
- [ ] 各ファイルの役割が明確か？
- [ ] 依存関係が明確か？
- [ ] 実装順序が合理的か？
