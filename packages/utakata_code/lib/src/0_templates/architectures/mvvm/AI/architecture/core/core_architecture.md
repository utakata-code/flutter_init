# Core 層アーキテクチャガイド — MVVM

## 概要

`lib/core/` はフィーチャー横断の**共通基盤**を管理する。
個別フィーチャーに属さない、アプリケーション全体で共有されるインフラストラクチャをここに配置する。

## ディレクトリ構造

```
lib/core/
├── routing/     # ルーティング設定
├── theme/       # テーマ・デザイントークン
├── di/          # 依存注入（グローバル Provider）
└── api/         # HTTP クライアント基盤
```

## 各モジュールの責務

### `routing/`
- GoRouter によるルーティング定義
- パス定数の管理
- ガード（認証チェック等）の定義

### `theme/`
- `ThemeData` の定義
- カラーパレット、タイポグラフィ、スペーシング等のデザイントークン
- ダークモード / ライトモード対応

### `di/`
- グローバルな Provider 定義
- Repository 実装のバインディング
- Service のシングルトン管理
- MVVM では Clean Architecture の `providers/` 層の代わりにここでDIを集約

### `api/`
- Dio クライアントのセットアップ
- インターセプター定義（ログ、認証トークン付与等）
- ベースURL・タイムアウト設定

## ルール

- Core 層はフィーチャーに依存してはならない（`import 'features/'` 禁止）
- フィーチャーは Core 層を自由に import できる
- Core 層の変更はアプリ全体に影響するため、慎重に行う
